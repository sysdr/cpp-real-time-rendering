C++ Real-Time Rendering — Vertex & Fragment Shaders

About this project

Purpose

This is Day 6 of the C++ Real-Time Rendering series. The application is a minimal OpenGL demo that introduces shader modules: a vertex shader and a fragment shader that work together to render a triangle with interpolated vertex colors.

Goals

  • Load and compile GLSL vertex and fragment shaders from files
  • Pass per-vertex data (position, color) through the pipeline
  • See color interpolation from vertex to fragment stage
  • Use VAO/VBO for geometry and a simple Shader class

Workflow

  • start.sh builds the app, runs the GL demo (window or headless), updates metrics, and starts this dashboard server
  • stop.sh stops the dashboard and any running demo process
  • Run the demo from here with "Run ./start.sh" or from the project directory

Why

Understanding the programmable pipeline (vertex → fragment) is the foundation for real-time rendering. This project keeps the scope small so you can see how shaders connect to C++ and how data flows from CPU to GPU.
